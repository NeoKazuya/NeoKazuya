<summary>How this is counted</summary>

The past seven calendar days, including today, in America/Los_Angeles. Projects are repositories owned by NeoKazuya, including private repositories; this profile repository is excluded. Only projects with activity are counted. The top three are ranked by authored PRs merged in the window, then commits, then project name.

PRs are authored by me and merged in the window. Commits are authored by my GitHub account, reachable on each repository’s default branch, and have a committer timestamp in the window. Unmerged branch commits are not counted. PRs and commits overlap and are never added into a combined score. Repository names and existing short descriptions are displayed; code, PR titles and commit messages are not published.

The timestamp on the card is the last successful refresh. [Refresh setup](SETUP.md).
